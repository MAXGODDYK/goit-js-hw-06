# goit-js-hw-06

Домашнє завдання 6 з JavaScript про `this` і приватні властивості класів.

| Файл           | Завдання                                                       |
| -------------- | -------------------------------------------------------------- |
| `js/task-1.js` | Акаунт користувача `customer` з методами для балансу та знижки |
| `js/task-2.js` | Склад `Storage` із приватним списком товарів                   |
| `js/task-3.js` | Конструктор рядків `StringBuilder` із приватним значенням      |

Відкрий `index.html` або [живу сторінку](https://maxgoddyk.github.io/goit-js-hw-06/)
і переглянь результати перевірочних викликів у DevTools → Console.
